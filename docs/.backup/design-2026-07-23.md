**Somnia** — AI-powered Dream Journal Analyzer (Frontend SPA)  
Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 + SWR

## 1. Project Overview

| Attribute | Value |
|-----------|-------|
| **Name** | Somnia Frontend (somnia-fe) |
| **Purpose** | Self-reflection dream journal with AI analysis, visualization, trends, companion chat, community sharing |
| **Architecture** | SPA (Next.js App Router) → Backend API (somnia-be) via HTTPS + Bearer Token |
| **Auth** | Bearer token in localStorage → `Authorization: Bearer <token>` |
| **Backend API** | `NEXT_PUBLIC_API_URL` (e.g., `https://be-somnia.hallojanu.xyz`) |

  const token = getToken();
  const res = fetch(API_BASE + path, {

      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...(options.json ? { "Content-Type": "application/json" } : {}),
    },
    body: options.json ? JSON.stringify(options.json) : options.body,
  });

  // 401 → clear token + redirect to /login
  if (res.status === 401) { clearToken(); router.push("/login"); }

  // Throws ApiError(status, message, fieldErrors) on !ok || !success

}

## 6. Data Fetching & State

### 6.1 `useApi` Hook (`lib/use-api.ts`)

```ts
function useApi<T>(path: string | null, deps: unknown[] = []) {
  const key = path ? [path, ...deps] : null;
  const { data, error, mutate } = useSWR<ApiResponse<T>>(key, fetcher, {
    revalidateOnFocus: false,
    shouldRetryOnError: false,
  });
  return {
    data: data?.data ?? null,
    meta: data?.meta ?? {},
    loading: path && !data && !error,
    error: error?.message ?? null,
    reload: () => mutate(),
    setData: (newData) => mutate({ data: newData, ... }, false),
    mutate,
  };
}
```

### 6.2 `useMutation` Hook (`lib/use-mutation.ts`)

```ts
function useMutation<T>(mutateFn, options?) {
  const [state, setState] = useState({ loading: false, error: null });
  const execute = async (args) => {
    setState({ loading: true, error: null });
    try { const res = await mutateFn(args); toast.success(options?.successMessage); return res; }
    catch (e) { toast.error(options?.errorMessage); throw e; }
    finally { setState({ loading: false, error: null }); }
  };
  return { execute, ...state };
}
```

## 20. Key Design Decisions & Rationale

| Decision | Rationale |
|----------|-----------|
| SPA (`output: 'export'`) | Simple static hosting, no Node server needed |
| localStorage token | Backend is cross-origin; cookies unreliable |
| SWR over React Query | Lightweight, built-in deduping, familiar API |
| Tailwind v4 + CSS Variables | Native dark mode, no config file, design tokens in CSS |
| Cord.com Maritime Palette | Calm, dreamy aesthetic; accessible contrast |
| Figtree Variable Font | Single font file, wide weight range, distinctive |
| Server Components (minimal) | Only root/auth layouts; all features client-side for interactivity |
| Typewriter Effect | Simulated streaming feel without SSE/WebSocket dependency |
| Local AI Lexicon | Offline symbol/emotion reference; works without backend analysis |
| Giscus for Comments | Zero-backend comments, GitHub-backed, spam-resistant |
| PDF via `window.print()` | No heavy PDF lib; browser print-to-PDF is universal |
